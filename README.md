of waiting GTA 6 is finally out, and my AI agent already got paid on
make.fun. The meme (`meme.png`) shows make.fun's ghost with its magenta
star coin over a Vice City sunset. The post on X is the entry; `POST.json`
names its address, and `main.ts` copies that file to `/output/POST.json`.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
